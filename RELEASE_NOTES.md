# Release notes — ARO `v1.0.1-preview.1`

- **Статус:** предварительный экспериментальный source snapshot.
- **Версия в `plugin.yaml`:** `1.0.1`.
- **Дата подготовки:** 27 октября 2026 г.

## В этом snapshot

- Публично описан нативный Hermes delegation backend `oscar_aro`.
- Для каждой native `delegate_task` PRIMARY может передать `reasoning_effort`: `low`, `medium`, `high` или `xhigh`.
- Если параметр задачи отсутствует, применяется фиксированный `xhigh` fallback.
- Плагин передаёт effort в route отдельной задачи и сохраняет заданные в конфигурации route-поля дочернего агента; сам модель не выбирает.
- В возвращаемом route задаётся `service_tier=normal`; совместимость зависит от выбранного маршрута и версии Hermes.
- Backend-specific настройки `delegation.backends.oscar_aro` не поддерживаются. Непустой блок или значение конфигурационного `reasoning_effort`, отличное от `xhigh`, приводит к отказу маршрутизации.

## Проверки

Из корня собранного snapshot, Python 3.10+ (только стандартная библиотека):

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
```

В этом snapshot команда выполнена успешно: **8 тестов**. Это provider unit tests с узким in-process stub для `agent.delegation_provider`; они проверяют поведение provider (уровни, fallback, некорректный ввод/конфигурацию, копирование route), но не регистрацию и dispatch в Hermes, не модель/API-вызов и не сетевую интеграцию.

Отдельный offline route-isolation отчёт фиксировал 7 тестов в изолированной среде с mock transport и без реальных API-запросов. Это иная проверка, не CI данного snapshot; синтетический SDK request не является live wire receipt.

Отдельная ограниченная живая проверка: два native child получили разные задания с `low` и `high` и завершились ответами. Проверка была привязана к child и SDK boundary; сериализованный live wire, провайдерский tier и внутренний compute не подтверждены.

Эти проверки не являются оценкой качества или сравнением одинаковых задач на разных уровнях. Снижение затрат, расхода токенов или квоты не заявляется.

## Совместимость и установка

Плагин предназначен только для Hermes build, совместимой с публичным интерфейсом delegation provider. Совместимость со всеми версиями Hermes не подтверждена. Проверьте официальную документацию и discovery-path целевой установки, а затем испытайте загрузку и route в изолированном профиле до изменения рабочей конфигурации. Готовая универсальная команда установки для этого snapshot не предоставляется.

## Известные ограничения

- Экспериментальный статус; не обозначается как production-ready.
- Выбор уровня остаётся за PRIMARY; автоматической классификации сложности задач нет.
- При пропуске параметра используется `xhigh`, поэтому автоматическая адаптация не гарантирована.
- Реальная семантика effort и результат зависят от выбранной Hermes/provider/model связки.
- Route копирует настроенные поля, включая `api_key`, если он присутствует; обращайтесь с route-конфигурацией как с секретной и не публикуйте её.
- Нет доказанной экономии или улучшения качества.
- Лицензия не указана; публичный просмотр исходников не предоставляет автоматически прав на повторное использование.
